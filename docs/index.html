This page is 100% static — no servers, no accounts, no API keys required. It asks a public reader service to render the Google Flights results page, then parses the prices right here in your browser. If the reader blocks one Google domain, the app automatically tries the next one in the list. Settings are saved in your browser only.

Accuracy first. The app defaults to an exhaustive search: every airport pair, every stay length and every single day of the date window is looked up, so the cheapest option it reports really is the cheapest on offer. Time is not a shortcut here — a 5-airport month-long sweep is ~620 lookups ≈ 35 minutes key-less. Keep this tab open while it runs; progress is checkpointed and a reload offers to resume.

Why a big search takes a while: the key-less reader serves roughly 20 lookups per minute per visitor (one lookup = one Google Flights page), and answers HTTP 429 past that. Rather than failing, the app queues its lookups under that rate and shows the wait, the elapsed time and an ETA in the progress line. A free reader API key lifts the limit, so paste one here if you want to sweep big airport sets quickly. Setting the ceiling above 0 caps the sweep (calendar days are spread across the window and the result header states exactly what was covered); 0 means exhaustive.
